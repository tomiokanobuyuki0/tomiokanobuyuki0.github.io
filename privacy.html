tn-calendar プライバシーポリシー

最終更新日: 2026年10月25日

取得する情報

tn-calendar は、Google Calendar API の calendar.freebusy 権限で、指定したカレンダーの空き時間（予定がある時間帯の開始・終了時刻）だけを取得します。予定の件名・説明・場所・参加者は取得しません。

使い方

取得した空き時間は、開発者本人が日程の候補を決めるためだけに使います。

保存と共有

空き時間の情報は、開発者本人のコンピューター上で処理するだけで、外部のサーバーには保存しません。第三者への提供・販売・広告への利用はしません。ログインに使う認証情報は、開発者本人のコンピューターにだけ保存します。

Google API サービスのユーザーデータに関するポリシー

tn-calendar による Google API から受け取った情報の使用と移転は、制限付き使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。

アクセスの取り消し

Google アカウントの サードパーティによるアクセス から、いつでも tn-calendar のアクセスを取り消せます。

English

tn-calendar reads only free/busy time ranges via the Google Calendar API (calendar.freebusy scope). It does not read event titles, descriptions, locations, or attendees. The data is processed only on the developer's own computer to choose meeting times, is not stored on external servers, and is never sold or shared with third parties. tn-calendar's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. You can revoke access at any time from your Google Account.
