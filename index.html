tn-calendar

tn-calendar は、開発者本人が日程調整に使うための個人用ツールです。一般向けには提供していません。

できること

ログインしたアカウントの権限で、指定したカレンダーの空き時間（予定がある時間帯とない時間帯）だけを Google Calendar API から取得します。予定の件名・説明・参加者などの内容は取得しません。

使う権限

  • https://www.googleapis.com/auth/calendar.freebusy（カレンダーの空き時間の閲覧）

English

tn-calendar is a personal tool used only by its developer to schedule meetings. It reads free/busy information (time ranges only, no event details) from Google Calendar using the calendar.freebusy scope. It is not offered to the public.
